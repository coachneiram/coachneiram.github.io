Aide

Une question, un problème ? Écris à coachingbymarien@gmail.com. Indique ton modèle de téléphone et, si la question touche l'abonnement ou l'IA, l'identifiant affiché tout en bas des Réglages (« ID nrm_… »).

Abonnement

Comment résilier ?

iPhone : Réglages → ton nom → Abonnements → Neiram. Android : Play Store → profil → Paiements et abonnements → Abonnements → Neiram. L'accès Premium reste actif jusqu'à la fin de la période payée.

J'ai changé de téléphone et je ne suis plus Premium

Dans l'app : Réglages → Neiram Premium → « Restaurer mes achats », avec le même compte Apple ou Google qu'à l'achat.

Comment utiliser un code promo ?

Réglages → Neiram Premium → « J'ai un code ». Sur Android, le code se saisit dans le Play Store.

Mes données

Où sont mes données ?

Sur ton téléphone uniquement. Fais régulièrement une sauvegarde : Réglages → Sauvegarde → Exporter. Elle se restaure sur un nouveau téléphone dès l'écran d'accueil.

Comment retirer mon accord pour l'IA ?

Réglages → Fonctions IA → « Retirer mon accord ». Plus rien n'est envoyé tant que tu ne l'as pas redonné.
